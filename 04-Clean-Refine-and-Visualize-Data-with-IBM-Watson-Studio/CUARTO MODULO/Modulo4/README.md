# Resumen: Refinar Datos en IBM Watson Studio

## Introducción
En este módulo, aprendimos a refinar datos usando la herramienta **Data Refinery** en **IBM Watson Studio**. A través de una simulación práctica, trabajarás en agregar una nueva columna para investigar una hipótesis relacionada con reclamaciones de seguros.

## Objetivos de Aprendizaje
Al finalizar este módulo, debería ser capaz de:
- Refinar datos utilizando la herramienta **Data Refinery**.

## ¿Qué se hizo en este módulo?
Durante la simulación, nos enfocamos en la hipótesis compartida por la patrocinadora del proyecto: las reclamaciones de seguros de automóviles por reparaciones mayores a $10,000 podrían ser fraudulentas y ayudar a predecir fraudes. Para ello, realizamos los siguientes pasos:

1. **Agregar una nueva columna**: Se añadió una columna que identifica cuáles reclamaciones superan los $10,000. Esto te ayuda a filtrar y enfocar el análisis en las reclamaciones que cumplen con ese criterio.
2. **Investigar la hipótesis**: Con la nueva columna, comienzas a explorar si existe una relación entre reclamaciones grandes y actividad fraudulenta.
3. **Preparar una visualización inicial**: Este primer análisis visual te servirá para profundizar en la investigación y ver si la hipótesis podría ser correcta.

## Nota Importante
La herramienta **Data Refinery** es muy avanzada y permite realizar muchas otras operaciones. Por ejemplo, podrías investigar si conducir con licencia vencida también se asocia a actividades fraudulentas. Pero en este módulo, el enfoque está en identificar reclamaciones mayores a $10,000.

## Conclusión
Al finalizar esta simulación, has refinado tu conjunto de datos para incluir una nueva columna que destaca las reclamaciones de más de $10,000. Este es un paso clave para investigar la hipótesis del proyecto y avanzar en la identificación de posibles fraudes.
