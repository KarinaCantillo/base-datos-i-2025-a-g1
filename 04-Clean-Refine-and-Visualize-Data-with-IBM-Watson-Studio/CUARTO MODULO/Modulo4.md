# Proyecto de Ciencia de Datos: Predicción de Fraude en Reclamaciones de Seguros de Automóviles

## Descripción
IBM Watson Studio es un entorno de desarrollo integrado (IDE) que ofrece la herramienta **Data Refinery** para limpiar, dar forma y visualizar datos.

### Objetivo
El objetivo de tu proyecto de ciencia de datos es predecir fraudes y actividades sospechosas para ayudar a reducir drásticamente las pérdidas debido al fraude. El fraude es un punto crítico para la compañía de seguros de automóviles.

### Datos
Trabajaste con un conjunto de datos ficticio de reclamaciones de seguros de automóviles con 975 filas y 38 columnas.

## Práctica de Simulaciones
Tuviste la oportunidad de practicar de manera práctica en simulaciones de IBM Watson Studio y la herramienta **Data Refinery** para realizar las siguientes acciones:

1. Provisionar el servicio de Watson Studio
2. Configurar un nuevo proyecto
3. Importar los datos de reclamaciones de seguros de automóviles
4. Limpiar el conjunto de datos
5. Refinar el conjunto de datos
6. Crear y estudiar una visualización de datos para obtener información
