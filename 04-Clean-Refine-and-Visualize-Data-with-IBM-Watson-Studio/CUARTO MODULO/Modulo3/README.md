# Resumen: Entender y Limpiar los Datos en IBM Watson Studio

## Introducción
En este módulo, enseña como entender y limpiar datos utilizando la herramienta **Data Refinery** de **IBM Watson Studio**. Limpiar los datos es una parte fundamental para asegurarte de que los resultados que obtengas sean precisos y útiles.


## Limpiar los Datos
Limpiar los datos es un paso crucial porque te permite eliminar toda la información innecesaria o irrelevante y mantener los datos que realmente pueden ayudar en la predicción de fraudes, que es el objetivo principal del proyecto.

### Pasos Realizados en la Simulación
En esta simulación, usaste IBM Watson Studio con la herramienta **Data Refinery** para entender y limpiar tu conjunto de datos. Los pasos fueron los siguientes:

1. **Revisar las columnas de datos**: Lo primero que hice fue revisar las columnas para entender qué tipo de información contenían y cómo se relacionaba con el fraude que quiero predecir.

2. **Seleccionar las columnas útiles**: Después, seleccioné las columnas que tenían datos importantes para la predicción, como la causa del incidente y las que contenían fechas y horas.

3. **Eliminar las columnas innecesarias**: También eliminé aquellas columnas que no aportaban nada, como las que tenían datos faltantes o información personal.

4. **Revisar estadísticas descriptivas**: Usé la pestaña **Profile** para revisar las estadísticas descriptivas, como la desviación estándar, lo cual me ayudó a decidir qué columnas eran realmente útiles para el análisis.

5. **Corregir los tipos de datos**: Finalmente, me aseguré de que las columnas tuvieran los tipos de datos correctos para que la herramienta pudiera hacer cálculos adecuados.

### ¿Por qué es importante este paso?
Entender y limpiar los datos es un paso esencial que puede tomar bastante tiempo. Los analistas de datos suelen pasar mucho de su tiempo en esta etapa para garantizar que los datos estén bien preparados y listos para ser utilizados en el análisis.

## Conclusión
Una vez que entendí y limpié los datos, ahora están listos para ser refinados aún más y usados en el proyecto para predecir fraudes. El siguiente paso será seguir refinando los datos y avanzar en el proyecto.
