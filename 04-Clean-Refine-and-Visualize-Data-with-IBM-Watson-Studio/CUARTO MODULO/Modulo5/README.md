# Resumen: Visualización de Datos en IBM Watson Studio

## Introducción
En este módulo se aprendió a visualizar datos utilizando la herramienta **Data Refinery** en **IBM Watson Studio**. Las visualizaciones permiten explorar la información desde diferentes ángulos, identificar patrones y descubrir relaciones de forma rápida.

## Objetivos del Módulo
Al finalizar, el participante debería poder:
- Crear visualizaciones a partir de datos preparados.
- Analizar cómo se relacionan las variables para identificar comportamientos fraudulentos.

## Proceso Realizado en la Simulación
Durante la simulación se realizaron 15 pasos para:
- Crear una visualización preliminar utilizando la pestaña de Visualizaciones.
- Generar un gráfico de dispersión (scatter plot) que relaciona variables independientes y dependientes.
- Experimentar con diferentes configuraciones en los ejes para observar distintos patrones en los datos.

## Insights Obtenidos
La visualización aportó información relevante respecto a la hipótesis planteada:
- **Reafirmación de la hipótesis**: Las reclamaciones por reparaciones superiores a $10K (representadas por puntos rosas) tienden a asociarse con fraude.
- **Excepciones observadas**: Se detectaron reclamaciones mayores a $10K que no fueron fraudulentas (puntos azules) y, además, se observó actividad fraudulenta en reclamaciones por debajo de $10K.
- Estos hallazgos indican que, si bien existe una tendencia clara, hay casos atípicos que requieren un análisis más detallado.

## Conclusión
La visualización de datos ha permitido extraer insights importantes para el proyecto. Se pudo confirmar la relevancia de las reclamaciones mayores a $10K en la detección de fraude, pero también se evidenció que el fraude puede presentarse en reclamaciones de menor valor. Estos resultados proporcionan información valiosa para que el departamento de Fraude de Reclamaciones decida los próximos pasos y reduzca las pérdidas financieras.
