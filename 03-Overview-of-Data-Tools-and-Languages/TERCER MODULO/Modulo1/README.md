# Introducción a Open Source y GitHub

## ¿Qué aprenderás en este módulo?
En este módulo, aprenderás sobre la importancia de la colaboración en el desarrollo de software de código abierto y cómo usar GitHub para gestionar proyectos de datos.

## Objetivos de aprendizaje
- Entender el valor de la colaboración y el uso de software open source en ciencia de datos.
- Conocer la función y beneficios de GitHub.

## ¿Qué es el software de código abierto (open source)?
El software de código abierto es aquel cuyo código está disponible públicamente y puede ser usado, modificado y compartido por cualquiera.

### Beneficios del open source para individuos y empresas:
- **Aprendizaje y desarrollo:** Permite adquirir nuevas habilidades y conectarse con expertos.
- **Innovación y ahorro:** Facilita el acceso a soluciones ya desarrolladas, reduciendo costos.
- **Colaboración global:** Fomenta la revisión, mejora y seguridad del software.

## Aspectos clave del software de código abierto
1. **Uso:** Cualquiera puede ejecutar el software bajo su licencia.
2. **Visualización:** El código fuente está disponible para su estudio.
3. **Modificación:** Cualquiera puede proponer mejoras o corregir errores.
4. **Compartir:** Se basa en la colaboración y el intercambio de conocimientos.

## Roles en una comunidad open source
- **Comunidad:** Grupo de personas que participan y se benefician del proyecto.
- **Contribuidor:** Aporta mejoras o soluciones al proyecto.
- **Committer:** Persona con permisos para aprobar cambios en el código.
- **Código de conducta:** Define las normas de comportamiento en la comunidad.
- **Guía de contribución:** Explica cómo colaborar en el proyecto.

## Git vs GitHub
### **Git**
- Es un sistema de control de versiones que permite hacer seguimiento a los cambios en el código.
- Se instala localmente en la computadora.
- Se puede usar sin GitHub.

### **GitHub**
- Es una plataforma en línea para alojar proyectos basados en Git.
- Permite colaborar con otros en proyectos de código abierto.
- Facilita la gestión de repositorios (carpetas con archivos, datos y documentos del proyecto).

## ¿Qué puedes hacer en GitHub?
- **Crear y alojar proyectos de código abierto.**
- **Contribuir a proyectos existentes,** proponiendo mejoras y corrigiendo errores.
- **Gestionar versiones del código,** revisando el historial de cambios.
