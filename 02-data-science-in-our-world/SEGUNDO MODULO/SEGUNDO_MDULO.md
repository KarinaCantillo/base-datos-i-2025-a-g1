# Resumen de Ciencia de Datos

## **MÓDULO 1: ¿Qué es la Ciencia de Datos?**

La **ciencia de datos** es un campo interdisciplinario que combina estadística, informática e inteligencia artificial para analizar grandes volúmenes de datos y extraer conocimientos valiosos. Su propósito es ayudar a resolver problemas complejos en diversas áreas como negocios, salud y finanzas.

Un científico de datos trabaja con herramientas como análisis de datos, modelado predictivo y machine learning para descubrir patrones y hacer predicciones.

**Ejemplo:**  
Una empresa de videojuegos quiere entender por qué sus empleados renuncian. Utilizando ciencia de datos, analizan factores como salario y distancia al trabajo para encontrar patrones en las renuncias.

## **MÓDULO 2: Metodologías en Ciencia de Datos**

### **¿Qué es una metodología?**

Una **metodología** es una estrategia general que guía las actividades dentro de un proceso. No depende de herramientas o tecnologías específicas, sino que proporciona un marco de trabajo para que los científicos de datos sigan un proceso estructurado y lógico para obtener respuestas o resultados.

Así como los científicos siguen el **método científico**, los científicos de datos necesitan una metodología que los ayude a resolver problemas.

### **Metodologías Clásicas en Ciencia de Datos**

A lo largo del tiempo, se han desarrollado varios enfoques metodológicos. Entre los más adoptados están:

1. **CRISP-DM (Cross-Industry Standard Process for Data Mining):**
   - Es el modelo más utilizado en la industria.
   - Se basa en seis fases: comprensión del negocio, comprensión de datos, preparación de datos, modelado, evaluación y despliegue.

2. **KDD (Knowledge Discovery in Databases):**
   - Se centra en la exploración de grandes volúmenes de datos para descubrir patrones útiles.
   - Fases: selección de datos, preprocesamiento, transformación, minería de datos e interpretación de resultados.

3. **SEMMA (Sample, Explore, Modify, Model, Assess):**
   - Utilizado por SAS Institute, enfatiza la exploración y transformación de datos antes de modelarlos.
   - Fases: muestreo, exploración, modificación, modelado y evaluación.

Cada metodología tiene sus ventajas y se elige según el contexto y la necesidad del proyecto.

## **MÓDULO 3: Seguir una Metodología en Ciencia de Datos**

Para llevar a cabo un proyecto de ciencia de datos, se sigue un proceso estructurado.

### **Los seis pasos clave del proceso**

1. **Comprensión del negocio:** Definir el problema que se quiere resolver.
2. **Exploración y preparación de datos:** Recopilar, limpiar y organizar los datos.
3. **Representación y transformación de datos:** Analizar los datos con estadísticas descriptivas (media, mediana, moda, etc.).
4. **Visualización y presentación:** Usar gráficos para interpretar y comunicar los hallazgos.
5. **Entrenamiento de modelos:** Aplicar machine learning para hacer predicciones.
6. **Despliegue del modelo:** Integrar el modelo en la empresa para su uso en producción.

**Ejemplo: Caso de estudio**  
Scott Hill, un científico de datos, aplica esta metodología en la empresa GAXR para predecir la rotación de empleados.

- **Recopila datos** sobre empleados (salario, distancia al trabajo, etc.).
- **Limpia los datos**, eliminando información irrelevante.
- **Aplica estadísticas descriptivas** para entender tendencias.
- **Entrena un modelo de machine learning** para predecir quién podría renunciar.
- **Despliega el modelo** para que Recursos Humanos tome mejores decisiones.

### **Visualización de Datos**

Los científicos de datos utilizan gráficos para presentar sus hallazgos. Algunos de los tipos más comunes son:

- **Gráficos de pastel:** Muestran proporciones dentro de un total.
- **Gráficos de líneas:** Ideales para mostrar tendencias a lo largo del tiempo.
- **Gráficos de barras y columnas:** Comparan categorías.
- **Diagramas de dispersión:** Muestran relaciones entre dos variables.

La visualización de datos debe ser clara, impactante y responder a la pregunta del negocio.

---

## **Conclusión**

La ciencia de datos es un proceso estructurado que permite resolver problemas con datos. Desde entender el problema hasta implementar modelos predictivos, cada paso es clave para tomar mejores decisiones basadas en datos.

Metodologías como **CRISP-DM, KDD y SEMMA** guían el proceso y garantizan que el análisis sea riguroso y útil. Finalmente, la visualización de datos ayuda a comunicar los resultados de forma efectiva para que sean comprensibles y accionables.
