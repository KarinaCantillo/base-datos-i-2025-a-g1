# Introducción a la Ciencia de Datos

## ¿Qué aprenderás en este módulo?
En este módulo aprenderás:
- Qué es la ciencia de datos.
- La importancia de la curiosidad para resolver problemas con datos.
- Las diferencias entre análisis de datos y ciencia de datos.

## ¿Qué es la ciencia?
La ciencia es un sistema que combina métodos y leyes científicas para obtener conocimiento práctico.

## ¿Qué es la ciencia de datos?
La ciencia de datos es el estudio del mundo a través del análisis de datos digitales. Combina métodos científicos, matemáticas, estadísticas, programación y herramientas avanzadas para descubrir patrones y generar información útil para la toma de decisiones.

Los científicos de datos preparan datos, los analizan y presentan resultados para identificar tendencias y realizar predicciones. Utilizan modelos para transformar datos crudos en conocimiento útil.

## La importancia de la curiosidad en la ciencia de datos
Una característica clave de los científicos de datos es la curiosidad. Hacen preguntas para descubrir patrones y entender fenómenos. Un método útil para esto es la técnica de los **5 Porqués**.

## La técnica de los 5 Porqués
Es un método para encontrar la causa raíz de un problema haciendo la pregunta "¿Por qué?" cinco veces de manera secuencial. Cada respuesta lleva a una nueva pregunta hasta llegar a la causa fundamental.

**Nota:** No siempre es necesario hacer exactamente cinco preguntas; el número puede variar según el problema.

## Ciencia de datos vs. Análisis de datos
Ambas disciplinas trabajan con datos y buscan convertirlos en información valiosa para los negocios, pero tienen diferencias clave:

| Característica    | Análisis de datos                                |             Ciencia de datos                              |
|-------------------|--------------------------------------------------|-----------------------------------------------------------|
| **Objetivo**      | Identificar tendencias y crear visualizaciones.  | Diseñar procesos para modelar datos y hacer predicciones. |
| **Enfoque**       | Describe lo que sucedió y por qué.               | Predice lo que sucederá y cómo actuar en consecuencia.    |
| **Herramientas**  | Dashboards, reportes, estadísticas descriptivas. | Algoritmos, inteligencia artificial, modelos predictivos. |

## Conclusión
La ciencia de datos y el análisis de datos son esenciales para la toma de decisiones basada en datos. Mientras que el análisis de datos se enfoca en interpretar el pasado y el presente, la ciencia de datos busca modelar el futuro mediante técnicas avanzadas.
